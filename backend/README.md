The backend is currently in the planning stage; no application service has been implemented yet. Local virtual environments are excluded from Git.

Read the [detailed implementation plan](IMPLEMENTATION_PLAN.md) for:

- Python/FastAPI project setup and local PostgreSQL startup.
- Firebase Authentication and Data Connect migration boundaries.
- Database models, API contracts, durable jobs, and TinyFish integration.
- PDF evidence extraction, readiness rules, and amendment history.
- Frontend cutover, tests, GitHub CI, deployment, and acceptance criteria.

The commands in that plan describe the intended workflow after its scaffold and configuration files have been implemented.
